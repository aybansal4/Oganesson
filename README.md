# Oganesson  
A custom CLI built to replace my earlier bash wrapper, cshift-cli.  

This project is a work in progress, more info will come soon.  


## My progress!  

- Have a handler for commands not built-in  
- Have an init system for running commands on startup and checking the aliases file and history (not fully functional)  
- Have a function to add to the history file  
- Have a function to run the previous command again (It works now!)  
- Have a function to clear the screen  
- Have a function to change directories  

It's actually functional now, but it basically functions as a wrapper to sh like the old project, this is temporary.
